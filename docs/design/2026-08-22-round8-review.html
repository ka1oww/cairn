Turn 16 — the screen after the paste

The itinerary parser is deterministic and runs on the phone; every day it returns carries a confidence — high, medium, or low — because the package is built to ask, not guess. A parser that can be wrong, with no screen to correct it, is a defect that stays invisible until a real trip finds it. These four surfaces are that screen: storyboard screen 3, straight after the paste box and the reading narration drawn in earlier rounds.

Confidence drives the layout, not a badge on it. High-confidence days collapse to one line each and slide by. No warning triangles, no red — an unsure parser is the design working, and the screen never looks broken.

16cCorrecting it

Three corrections in the fewest taps there are: hold a stop and tap its day; flip day-first/month-first once for the whole paste; tap any text to retype it in place. No edit mode, no second screen, no spreadsheet.

Not a dead end, and never the person's fault. The copy blames the text's shape, not the paster; there is no "error", no red, no empty-state illustration of failure. The paste is shown kept, and three doors stand open: build the days by hand, try a different paste, or start empty — the trip's dates already exist, so empty days are one tap.
